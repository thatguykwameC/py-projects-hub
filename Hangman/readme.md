## Hangman Game

A simple game of hangman.

print(Word to guess: **\_\_**)

1. Prompt the user to guess a letter.
2. Checks if the letter is in the word
3. wrong guess means deduct a life
4. 6 lives in total
5. if the user guesses the correct letter it should replace the underscore being displayed
6. Prints a "You win", when all words are successfully guessed
